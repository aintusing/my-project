# Radar: мемкоины, крипта, инсайдеры, руководители

Прототип. Нужен Python 3.12, сторонних пакетов нет. Это не инвестиционная рекомендация.


```powershell

```

```powershell
git -c core.longpaths=true clone https://github.com/koala73/worldmonitor.git vendor/worldmonitor
```

```powershell
git -C vendor/worldmonitor -c core.longpaths=true checkout 055a1fd
```

## Запуск

Двойной клик по `run-radar.cmd` или:

```powershell
python -m radar watch --port 8765
```

Панель: http://127.0.0.1:8765/ . Сбор идёт каждые 5 минут (минимум 120 секунд, параметр `--every`), открытая страница перечитывается раз в минуту. Остановка: `Ctrl+C`. Работает, пока открыто окно и включён компьютер. В автозагрузку ничего не прописано.

## Команды

| Команда | Что делает |
|---|---|
| `python -m radar scan <адрес>` | Проверка токена на признаки rug pull |
| `python -m radar discover trending` | Тренды (`new`, `boosted`, `coingecko`) |
| `python -m radar news --risk` | Издания и регуляторы (`--find PEPE`) |
| `python -m radar social` | Telegram и X |
| `python -m radar hacks` | Взломы за 30 дней |
| `python -m radar execs` | Свежие 8-K Item 5.02 |
| `python -m radar insiders` | Свежие формы 4 |
| `python -m radar sources` | Реестр источников |
| `python -m radar --json <команда>` | Вывод в JSON (кроме `watch`) |

## Свои токены

Создайте `data/watchlist.txt`: один адрес на строку, `#` начинает комментарий. Эти токены проверяются каждый цикл, смена уровня риска пишется в консоль.

## Ключи (необязательно)

Задаются переменными окружения в том же окне перед запуском. Файлы с ключами в проект не кладите.

| Переменная | Зачем |
|---|---|
| `X_BEARER_TOKEN` | Посты аккаунтов X через официальный платный API. **Этот код с настоящим токеном не проверялся** |
| `SEC_USER_AGENT` | SEC просит указывать название приложения и контакт |

## Что подключено

| Слой | Источники |
|---|---|
| Рынок | DEX Screener, GeckoTerminal, CoinGecko |

| Взломы | DefiLlama |

**Не подключены** (нужны платные или личные ключи): Nansen, Arkham, Bubblemaps, Birdeye, Helius, Etherscan. Они есть в реестре как сайты для ручной проверки.

## Как читать вердикт

| Вердикт | Смысл |
|---|---|
| Критический риск | Honeypot, уже случившийся rug, право менять балансы, налог от 50% |
| Высокий риск | Эмиссия, заморозка, незаблокированные LP, высокая концентрация и подобное |
| Есть предупреждения | Слабые признаки |
| Явных флагов не найдено | Проверки ничего не увидели. Это **не** «безопасно» |
| Недостаточно данных | Источники безопасности не ответили или сеть не поддерживается |

## Известные ограничения

- Пороги подобраны вручную и на исторических rug pull не проверялись. Доли ложных тревог и пропусков неизвестны.
- Rug через продажу крупными держателями или связанными кошельками виден плохо.
- Концентрация держателей может включать биржевые кошельки.
- Граф инсайдеров RugCheck шумный даже на крупных токенах.
- Аккаунты X внесены по памяти модели и не сверены. Telegram-каналы проверены только на то, что открываются и содержат сообщения, а не на официальность.
- Пометка «тревога» ставится по ключевым словам в заголовке и даёт шум.
- Бесплатные API имеют лимиты, их значения не подтверждены.
- Условия использования источников для коммерческого продукта не проверялись. Это нужно сделать до продаж.
